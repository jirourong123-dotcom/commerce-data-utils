# Security

Never submit live credentials, personal data, actual orders or private business exports in issues, examples or pull requests. Use invented inputs for reproduction. Until a private disclosure contact is configured, do not post exploitable vulnerabilities or sensitive details publicly; contact the repository owner through an existing private channel.

This library performs data transformations only. It is not an authentication, authorization or transaction boundary. Callers must validate untrusted input and enforce their own access controls. No production integration is included.
