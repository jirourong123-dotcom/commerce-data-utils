# Contributing

This project is MIT-licensed. Run `npm test` and `npm run demo` with Node.js 22 or later. Do not add external services or real datasets to tests. New files require review and an explicit update of the public-tree allowlist in `tools/check-public-tree.js`.

Keep the package dependency-free unless a reviewed change explains the need. Do not add production deployment jobs, private repository checkouts, credentials, automatic uploads or scheduled workloads to the public workflow.
